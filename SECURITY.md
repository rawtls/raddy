# Security policy

Raddy is an early-stage project. Security fixes are developed on `main` and released for the latest minor version. Older minor versions are not maintained separately.

Use **Security → Advisories → Report a vulnerability** in this repository when GitHub private vulnerability reporting is available. Otherwise, contact the repository owner privately using a contact method listed on their GitHub profile. If you cannot reach them privately, open an issue asking for a private contact channel, without disclosing the vulnerability.

Include the affected version, a minimal configuration with secrets removed, expected and observed behavior, and a reproducible test. Do not post production tokens, private keys, customer traffic, or exploit details in public issues. Test only systems you own or are authorized to test.
